This repository contains code used the run the experiment described in our manuscript ["Listening with your heart: The heartbeat shapes auditory object formation by suppressing the early neural response to sound."](https://doi.org/10.64898/2026.08.17.745255)

`environment.yml` is the [conda](https://docs.conda.io/projects/conda/en/latest/user-guide/install/index.html) environment file containing the software packages necessary to run the code. 

`experiment.py` contains the main experiment code, implemented with the [PsychoPy](https://github.com/psychopy/psychopy) package, but you shouldn't run it directly. Instead, you run the experiment by running `python main.py`, which coordinates the online ECG processing pipeline. 

Online ECG processing and peak detection is implemented with [Lab Streaming Layer](https://labstreaminglayer.readthedocs.io/info/intro.html) (to access data from our electrophysiology amplifier in real time) and [LabGraph](https://github.com/facebookresearch/labgraph). LabGraph is a neat tool that lets you specify different processing steps as "nodes" (specified as Python classes) that you chain together in a directed "graph." Once you've done this, it handles all the parallelization for you, so by the time we're at our final node, `experiment.py`, we don't need to worry about the details of ECG processing... the time of the most recent QRS complex is just something we can access in our code (pretty cool). LabGraph node definitions, implementing the [Pan-Tompkins algorithm](https://en.wikipedia.org/wiki/Pan%E2%80%93Tompkins_algorithm), are tucked away in the `util` subdirectory with some other (PsychoPy) helper code.
